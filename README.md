# E-Commerce — Week 4 Case

Setup and run
```bash
git clone https://github.com/Dbinus/Aksub-Week4-FE.git
cd ./Aksub-Week4-FE/
npm install
npm run dev
```

Buka browser `http://localhost:5173`

### Penjelasan singkat

- Menggunakan Vite + React

- Aplikasi dipecah ke beberapa komponen di file berbeda

- Menggunakan hook useEffect untuk melakukan data fetching

- Menggunakan loading state dan error state yang jelas

- Menggunakan Fake Store API untuk sumber data ([https://fakestoreapi.com](https://fakestoreapi.com))

- Design sebisa mungkin mengikuti figma (tidak sama persis)
